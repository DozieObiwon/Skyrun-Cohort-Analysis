# Skyrun Cohort Analysis for Retention

Welcome to the **Skyrun Cohort Analysis** repository! This project analyses customer behaviour, retention patterns, and key segmentation insights to help drive better business decisions.

Project Structure

* **`Skyrun Customer Analysis FinalReport.docx`**: The comprehensive final written report detailing project findings, insights, and recommendations.
* **`Skyrun_analysis.ipynb`**: The Jupyter Notebook containing the core data analysis, data cleaning, and modelling code.
* **`skyrun dataset.csv`**: The primary dataset used for this cohort analysis.
* **`customer_segment.png`**: Visual representation of customer segmentation results.
* **`retention_heatmap (1).png`**: Heatmap visualisation tracking user retention cohorts over time.

Key Highlights
* **Cohort Analysis:** Tracked user engagement and retention trends across different groups.
* **Customer Segmentation:** Grouped customers to identify high-value behaviors and target audiences.
* **Data Visualisations:** Generated insightful heatmaps and segment charts to clearly present metrics.

Tools & Technologies
* **Python** (Jupyter Notebook)
* **Data Analysis & Visualisation Libraries** (Pandas, NumPy, Matplotlib, Seaborn, etc.)
* **Microsoft Word** for final reporting
